# Sistema de Control Escolar Gamificado (Majo)

Una plataforma web de gestión escolar inspirada en Google Classroom, que incorpora elementos de gamificación para motivar a los estudiantes a través de un sistema de experiencia (XP), logros y tablas de clasificación.

## Características Principales

* **Roles de Usuario:** Accesos diferenciados para Maestros y Alumnos.
* **Gestión de Clases:** Creación y unión a clases mediante códigos únicos.
* **Calendario Integrado:** Organización de tareas, entregas y eventos escolares.
* **Gamificación:**
  * Sistema de puntos (XP) que los alumnos ganan al entregar tareas.
  * Desbloqueo de logros por participación y desempeño.
  * Tabla de clasificación para fomentar una competencia sana.
* **Base de Datos Relacional:** Gestión segura de usuarios, clases y calificaciones.

## Tecnologías Utilizadas

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP
* **Base de Datos:** MySQL
